# NodeDrift

NodeDrift enables high-performance, real-time data processing in scalable Server and Cluster configurations with auto-scaling capabilities.

NodeDrift is built to be simple and practical, focusing on doing one thing well.

## Installation

1. Clone the repository: `git clone https://github.com/irenascent/NodeDrift.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

NodeDrift is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
